# Pace and pause

Original to Creator Studio (2026-10-20, draft; ramp mode 2026-10-21). Voice- and project-agnostic: every number is a project setting.

Makes the delivered pace match the direction where the voice ran ahead of it, and gives rests the length the project asks for. Time only: no level, tone or word change, no re-render.

```
<join step>  ->  pace-and-pause (this)  ->  <master step>  ->  measure gate
```
Chain order, for any narration workflow that has a join and a master:
- The master takes `<name>_paced.wav` (or the join output unchanged on a pass-through), never the join output beside it.
- The `@ed` pace marks come from an `emotional-director` pass that runs before voice direction. A chain without one has no marks: add it first.
- The split map (each entry with its `rest_type`) comes from the voice-direction step. It is optional; without it, `land` rests are not checked against join targets.
- After the master, run the measure gate below again on the mastered file. A review gate after the join may need a line for this step's edit list.

In a chain that uses a rate taper (`audio-treatment` -> "Rate taper and chain order") this step **replaces** the separate rate ramp: join -> pace-and-pause (taper folded in) -> softening -> closing taper. Never run the ramp again after it.

**Why post.** ElevenLabs v4 has no speed control (`speed` is rejected on v4), and tags do not fix pace. [measured, one v4 voice, single takes] a paragraph-opening sentence ran ~13-14% faster than its passage's base rate although it was tagged both times, against a < 8% bar. Evidence is one voice, one model, one take per segment: verify on yours.

## Opt-in rule (read first)
This skill serves every kind of narration, not only sleep. **Nothing slows down and no rest ramps unless the project turns it on in its own `project.json`.**
- **No `audio.pace` block (missing or `null`, as in the project template):** pass-through. No output file; the join output goes to the next step unchanged. Report `pace: not configured (pass-through)`. **Except for an episode with picture:** there a missing block is a stop-and-ask, not a silent skip. Show the pause notes and ask the user whether to set `audio.pace` (at least the punctuation and sentence rest keys) or to pass through; record the answer in `status.md`.
- **`audio.pace` present, `ramp` missing or `false`: neutral mode.** The existing behaviour: only sentences above their mark's ceiling are slowed (with the project's own `base_wpm`, `mark_ratio`, `max_stretch`), and only `land` rests are lengthened (`land_rest_s`). No rest ramp, no rest ceiling, no monotonic wpm ceiling, no tail-fade extension.
- **`audio.pace.ramp: true`: ramp mode.** Everything in "Ramp mode" below switches on. Its method and commands are in `references/ramp-mode.md`.
- **Always on (both modes, no slowing involved):** sentence alignment from whisper.cpp word times with ellipsis as a sentence end (word times find the sentence, never a cut point inside it: a pause inside a sentence is placed only by "Punctuation pause placement" below); the `@ed` mark check on every paragraph; the per-boundary `rest_type` and designed-transition rule; the end-tail handoff; the long-sentence guard **only when** `long_sentence_words` is set (off by default); C1/C2 as warnings.

## Rules
- **Numbers live in the project**, in `project.json` `audio.pace` (below), as `audio-treatment` reads `audio.treatments.<name>`. Neutral mode needs `base_wpm`, `mark_ratio`, `max_stretch`; ramp mode needs `base_wpm`, `mark_ratio`, `rest_ramp`. A missing required key: skip that part and say so (or ask). Never invent one or borrow another project's. Optional keys fall back to the defaults below, reported as "from skill default".
- **Separate output**: new 24-bit WAV `<name>_paced.wav` plus `<name>_paced.edits.json`. Never overwrite the input; refuse if the output exists (`ffmpeg -n`).
- **Never cut into speech.** Every cut, fade and stretch boundary sits inside a measured silence. A breath is speech. A boundary with no silence on one side is skipped and flagged.
- **Splice fades at every insert or split.** This is the one home of the voice-edit fade rule; other skills point here. Any inserted pause, set rest or split of the voice gets a fade-out of **at least 100 ms before the cut, linear in dB** (for example 0 dB at 100 ms before the cut, about -24 dB 10 ms before it, -60 dB at the cut; tested filter in `references/ramp-mode.md` § 4), and a fade-in of about 10 ms after it. `crossfade_ms` sets only the crossfade into and out of the rest fill; it never shortens the fade-out, which is never under 100 ms (a longer one is the project's choice). [observed, one long-form narrated documentary] 2 ms fades were heard as cut-offs; after producer review the project settled on 100-120 ms dB-linear fade-outs. A word tail must never drop from speech level to digital silence faster than its natural decay (about 120 ms down to the noise floor): where the native gap is shorter than the tail (words run together across a comma), keep the tail per `tail_min_s` and fade over it, or skip the insert and flag it. A 2 ms splice fade is a cut-off, not a fade. The fade shapes how the word ends; what fills the gap after it is the fill rule below. **QC** at every insert, on the post-edit clock (each insert's position = its parent-take position plus the summed length of every earlier insert, then mapped through any later assembly offsets): on 5 ms RMS blocks, the voice tail takes **at least 35 ms to fall from -25 to -45 dBFS**, and the fade reaches -60 dBFS or lower at the cut; the voice nulls against the previous version outside ±35 ms of the changed inserts.
- **Fill every insert inside a sentence with room tone.** This is the one home of the insert-fill rule; other skills point here. A pause inserted **inside a sentence** (after a comma, colon or dash, and at any split within a line) is filled with room tone matched to the take's own floor (`from_program`, below) and crossfaded into and out of at both ends. It is never left as digital silence, whatever `room_tone_source` says: against a playing bed, a hole of digital silence mid-sentence is heard as a skip, like a call losing connection, however well the word fades. Digital silence is allowed only at rests **between** sentences or sections, and only when the project opts in (`room_tone_source: "none"`). This is why the rule exists: a pause inside a sentence longer than about 0.3 s no longer sounds continuous without room tone, and comma pauses are commonly set longer than that. The pause length itself stays the project's setting (`punct_pause_s`).
  - **`from_program`**: tone cut from the take's own floor between words near the insert (no breath, no word tail, no click), looped to the insert's length, at the level of the floor on either side. One insert: `ffmpeg -hide_banner -nostats -n -ss <floor_start> -t <floor_len> -i <take>.wav -af "aloop=loop=-1:size=<floor_len × rate>,atrim=duration=<insert_s>" -c:a pcm_s24le tone_<n>.wav`, then crossfade it in and out (`acrossfade=d=<f_s>`, or the editor's crossfade). A project room-tone file can replace it (`room_tone_source: "<path>"`).
- **Slow only.** Rubber Band never speeds up. Only sentences above their ceiling move, and only down to the ceiling, limited to `max_stretch`.
- **Pace marks on every paragraph.** The directed script carries an `@ed Pn` line with `pace=` for every paragraph, inline. There is no separate add-on pace file, and the skill never reads one. A paragraph without a mark is a direction error: stop and send it back to `emotional-director`; never default its pace.
- **Designed transitions keep their length.** A split-map boundary with `rest_type: "transition"` and a `target_s` keeps that designed length; it is never snapped to the paragraph target (it is still held to `rest_max_s` in ramp mode, flagged if cut down).
- **Pauses stretch with speech**: rests are set after the stretch, and everything is re-measured after.
- **Punctuation pauses and the sentence rest range are opt-in keys** (`punct_pause_s`, `sentence_rest_s`; "Rushed delivery" below). Without them, commas, colons and dashes keep their delivered gaps.
- **Then the voice is locked.** After this step and the tone treatment, the voice is never processed again and the timeline is retimed to its new length: `audio-treatment` → "Voice lock".
- **Pauses are placed by hand, after generation.** The voice is rendered without pause tags for timing; the pauses are placed here, on the rendered take. The starting list is the pause notes (`elevenlabs-voice-director` → "Pause notes"): each note's place, rest type and target range. With `audio.chunking.split_at` set, the pauses at split-map entries are made at the join instead (`audio-treatment` → "Split-map assembly"), not cut in here. The user can move, lengthen, shorten or drop any pause by ear; record every change against its note (`changed by ear`) in the edit list. A pause the user adds that has no note gets one, so the picture and breather stages see it too.
- **Section breathers are not rests.** Music-only breaks between story sections are an assembly step (`filmcraft` → "Section breathers"), not a pace-and-pause insert: never lengthen a rest or a `transition` rest to make one.

## Ramp mode (`audio.pace.ramp: true` only)
- **Rest ramp per type.** Each boundary is `sentence`, `paragraph` or `transition`. Its target = linear interpolation of that type's `rest_ramp.<type>.start_s` -> `end_s` by the boundary's position p between story start and E (end of the last word), p in 0..1. A type with no ramp keeps its delivered rest and is reported. `land` lines take `max(target, land_rest_s)` when `land_rest_s` is set.
- **Hard ceiling.** No rest above `rest_max_s` (default 5 s), whatever the ramp, `land_rest_s` or split map says.
- **Rests are set, not only added.** The measured silence is replaced by a rest of the target length, filled per `room_tone_source` (digital silence only when the project opts in, and only at these between-sentence rests; the fill rule above), so a rest can also get shorter. Splice: `crossfade_ms` (50 ms) crossfades at every cut, with the splice fade rule above at each word tail. If the natural tail after the last word (silence start minus whisper word end) is under `tail_min_s` (0.3 s), keep audio to word end + `tail_min_s` and extend the fade-out over it, so speech does not cut off. The kept tail counts toward the rest.
- **Slowness comes mainly from rests, not stretch.** Stretch is a correction for sentences over their ceiling, capped at `max_stretch` (default 1.10, never above 1.10; a project value above it is lowered to 1.10 and reported). Pace factor x taper factor shares the same cap. **Every sentence that hits the cap is logged** (`capped` in the edit list and `.edits.json`): a re-render candidate.
- **wpm ceiling never rises.** Per sentence, ceiling = `base_wpm x mark_ratio[pace] x (1 + tolerance_pct/100)`, then `min` with the `wpm_ceiling` line (`start_wpm` -> `end_wpm`) if set, then a running minimum from start to end, so it is monotonic non-increasing. `wpm_ceiling.end_wpm` above `start_wpm`: stop and report.

## Rushed delivery: punctuation pauses and varied sentence rests
[observed in one long-form narrated documentary; confirm by ear] A read that feels rushed (and, with harsh sibilance, tiring) is fixed in two parts: timing here, tone in `audio-treatment` → "De-harsh treatment". The timing part, when the project sets the keys:
- **Punctuation pauses** (`punct_pause_s`): **a fallback when the project renders at split points.** With `audio.chunking.split_at` set (`elevenlabs-voice-director` → Step 6 "Split granularity"), a mark that has a split-map entry got its pause at the join (`audio-treatment` → "Split-map assembly"): skip it here and list it as `split point`. This rule then covers only the marks that are not split points; without `split_at`, every mark as before. The pause after a word whose script text ends in a comma, colon or dash is brought up to its target, inserting at most `target − natural gap` inside the verified gap (placement below), filled with room tone from the take's own floor and crossfaded in and out (Rules: fill rule; never digital silence). Starting values: comma about 0.38 s, colon and dash about 0.50 s. A comma with no measurable silence after it (no run of at least `punct_place.min_gap_ms` below the floor threshold: the voice ran through it) is skipped and flagged, never cut into.
- **Punctuation pause placement.** [measured, one v4 voice, one 10-min episode] whisper.cpp word times were off by −0.40 to +0.45 s at commas, and taking "the quietest 10 ms near the word time" as the comma put 11 of 49 comma pauses at the wrong place, 4 of them inside a word (a stop closure such as e‖quator or ep‖isode), then gave the tightest joins the longest silence. So a pause inside a sentence is placed only where **all** of these hold, and the defaults below are `punct_place` keys (Project settings):
  - **Between the right two words.** The mark sits between two script words; ASR word **order** against the script (as in Step 3) gives an estimate, which only orders the candidates (nearest first). [measured, same episode] word times were off by up to 1.6 s at one comma, so never place from a whisper time alone; search the sentence's gaps and let the ASR check below pick.
  - **A real gap.** A contiguous run of at least `min_gap_ms` (40 ms) below the take's local floor + `floor_margin_db` (floor = 10th percentile of 5 ms block levels over ±3 s); a single quiet 10 ms block is not a gap. [measured] the in-word stop closures the old method chose were 15-35 ms long. The cut goes at the quietest 10 ms inside the run.
  - **ASR shows the boundary there.** Transcribe about 2.5 s before and 2.5 s after the cut point, each alone (retry at 1.4 s): the before side must end with the script word before the mark and the after side must start with the script word after it (case and punctuation folded, whole words only; a word ASR writes as two, `may be` for `maybe`, counts).
    - **Each side alone, never one window across the cut**, and with a small English model (whisper.cpp `small.en`), or at least never a large model alone. [measured, one v4 voice, one insert] a cut in the 30 ms stop closure inside `a‖cross` ("edge to edge, across the tropics", no pause delivered at that comma) passed when large-v3-turbo read the combined windows as `edge, ‖ across`; small.en on each side alone heard `…kilometers edge to edge…` and `Cross the tropics.`, and with the insert removed `edge-to-edge across the tropics`. [inferred] A larger model fills in the expected word from context.
    - **Whole-word match on both sides.** The last word before the cut and the first word after it must each match the script word whole. A fragment is a reject whichever end it is: `Cross` for `across` (head cut off) as much as `ep-` for `episode`. [measured, same episode] the 8 other run-together joins passed this per-side test.
    - **Re-run on the built voice.** Repeat this per-side check at every insert on `<name>_paced.wav` (post-edit positions, Step 7), not only at planning time; an insert that fails there is removed and logged as skipped.
  - **Never inside a word.** A cut inside an ASR word leaves a fragment of it on both sides (`ep-` ‖ `episode`, `most` ‖ `water`, `physic` ‖ `s`), so the check above rejects it; never relax it to "close enough" spelling. Do not rely on whisper.cpp word spans for this: [measured] their word ends overran real pauses by 0.1-0.7 s, so a span test either rejects good commas or misses a split word. Log the span overlap as a warning only.
  - **None passes: skip and log** (place, every candidate tried, the ASR text, the reason). Never fall back to the quietest point.
  - **Size.** Insert = `max(0, target − natural gap)`, never more (natural gap = the verified run). A run-together join (natural gap under `run_together_s`) is capped at `run_together_cap_s` (0.15 s) and listed as capped, so the longest silence never lands on the tightest join.
- **Sentence rests** (`sentence_rest_s`, neutral mode): each sentence-end rest is set inside the range, varied rather than fixed (spread across it by sentence weight or a simple cycle; never the same value three times running). Starting values: 0.80-0.96 s, and at least 1.0 s after a fast sentence (one over its ceiling or `capped`). In ramp mode `rest_ramp` sets sentence rests and this key is ignored (reported).
- Starting block a user can copy into `audio.pace` (numbers become the project's once saved there):
  ```json
  "punct_pause_s": { "comma": 0.38, "colon": 0.50, "dash": 0.50 },
  "sentence_rest_s": { "min": 0.80, "max": 0.96, "after_fast_min": 1.0 }
  ```

## Project settings (`audio.pace`)
| Key | Default | Mode | Meaning |
|---|---|---|---|
| `ramp` | `false` | both | `true` turns ramp mode on. Missing or `false` = neutral. |
| `base_wpm` | required, no default | both | The project's target base rate. Not the voice's untagged rate (an untagged v4 voice measured near 200 wpm). |
| `rate_definition` | `"phonation"` | both | `phonation` = words / speech time excluding pauses; or `articulation`. Base and sentence must match. |
| `mark_ratio` | required, no default | both | `{ "slower", "steady", "brisker" }`: ceiling as a multiple of base. |
| `tolerance_pct` | `8` | both | [inferred] Allowed overshoot before a sentence moves. |
| `max_stretch` | neutral: required; ramp: `1.10` | both | Cap on the slow-down factor. Ramp mode never exceeds 1.10. |
| `wpm_ceiling` | `null` | ramp | Optional `{ "start_wpm", "end_wpm" }` line, `end_wpm <= start_wpm`. |
| `rest_ramp` | `null` (required in ramp mode) | ramp | `{ "sentence": {"start_s","end_s"}, "paragraph": {...}, "transition": {...} }`. A missing type is not ramped. |
| `rest_ramp_curve` | `"linear"` | ramp | Only `linear` is defined. |
| `rest_max_s` | `5` | ramp | Hard ceiling on any rest. |
| `tail_min_s` | `0.3` | ramp | Shorter natural tail -> fade-out extended into the rest. |
| `land_rest_s` | `null` | both | Neutral: target rest after a `land` line (`null` = skip land rests, say so). Ramp: a floor for that rest. |
| `rest_follows_taper` | `false` | neutral | Scale the land target by the local taper factor. |
| `rest_tolerance_pct` | `1` | neutral | Neutral gate band for land rests and split joins. |
| `rest_gate_pct` | `15` | ramp | Measure-gate band around each ramped (or designed) target. |
| `crossfade_ms` | `50` | both | Crossfade into and out of the rest fill at every cut. The word-tail fade-out is separate and never under 100 ms (splice fade rule). |
| `silence_detect` | `{ "noise_db": -40, "min_s": 0.25 }` | both | Matches the `audio-treatment` QC setting. |
| `room_tone_source` | `"from_program"` | both | Fill for rests: a file, `from_program`, or `none` (digital silence, a project opt-in for rests between sentences or sections only). Inserts inside a sentence are always room tone (Rules: fill rule). |
| `taper` | `null` | both | Rate taper: start anchor, any standing intro at 1.00x, end factor, curve. `null` = no taper (say so). |
| `end_tail_s` | `20` (fallback) | both | Trailing silence after E, passed to the closing taper as its pad. Report when it is the fallback. |
| `long_sentence_words` | `null` = off | both | Long-sentence guard threshold at the tagging/split step (projects commonly set 30). |
| `punct_pause_s` | `null` = off | both | `{ "comma", "colon", "dash" }`: target pause after a word ending in that mark. A missing mark keeps its delivered gap. With `audio.chunking.split_at` set, also the target of a `phrase` split-map entry, set at the join; this skill inserts only at marks that are not split points. |
| `punct_place` | `{ "min_gap_ms": 40, "floor_margin_db": 38, "run_together_s": 0.10, "run_together_cap_s": 0.15 }` | both | Placement and size checks for `punct_pause_s` ("Punctuation pause placement"). [measured, one v4 voice] a 38 dB margin on a −83 dBFS take floor is −45 dBFS; keep the threshold between −50 and −40 dBFS. |
| `sentence_rest_s` | `null` = off | neutral | `{ "min", "max", "after_fast_min" }`: varied sentence-end rests inside the range; the floor after a fast sentence. |

## Steps
1. **Intake.** Stitched speech (the join output), the directed script with `@ed` lines, the split map if any, the pause notes if any, `audio.pace`. No `audio.pace`: pass through, or stop and ask for an episode with picture (Opt-in rule). Check an `@ed` mark on every paragraph (Rules). Missing required keys for the mode: stop and ask. Input already paced or tapered: stop. If `long_sentence_words` is set, list any sentence over it (it should have been split before render; report, do not re-render).
2. **Marks.** Drop the `@ed` lines. Pace per sentence = the passage's `pace=`, changed by an `@ed-shift` from that sentence on (shift anchors keep the `emotional-director` numbering and are matched by their three-word check). [inferred] `land` on `@ed Pn` = after the passage's last sentence; on `@ed-shift Pn.sK` = after sentence K. Ceiling per mode (ramp mode: monotonic, above).
3. **Align and measure.** `whisper-cli -m <model> -f <in>.wav -ojf -ml 1 -sow -of <name>` (full JSON, one word per segment, word timestamps). For alignment a sentence ends at `.`, `!`, `?`, `…` or `...` followed by whitespace or the end of the text: **an ellipsis is a sentence end here**. Match ASR words to each sentence in order; count words from the script, times from ASR; a sentence that does not match cleanly is skipped and flagged. Rate per `rate_definition`. Gaps: `ffmpeg -hide_banner -nostats -i <in>.wav -af silencedetect=n=<noise_db>dB:d=<min_s> -f null -`; each boundary's rest = the silence between its last word end and the next word start. Comma, colon and dash pauses are **not** taken from these word times or from the nearest quiet frame: they are found and verified by "Punctuation pause placement" (Rushed delivery). Boundary type: split-map `rest_type` where the boundary is a split, else `paragraph` at a paragraph break, else `sentence`. A split-map entry without `rest_type` is read as `paragraph` and flagged. A `phrase` entry (`audio.chunking.split_at: "phrase"`) is inside a sentence, not a boundary between sentences: its pause was set at the join, and it is listed, not reset.
4. **Decide.** Pace factor = `measured / ceiling` when above ceiling, else 1.00, times the taper factor, limited to `max_stretch` (limited = `capped` flag). Ramp mode: each boundary's rest target (Ramp mode).
5. **Stretch.** Neutral mode, as before: one Rubber Band `--timemap` pass anchored only at silence midpoints, `rubberband -3 --timemap <name>.timemap -D <total_out_s> <in>.wav <name>_stretch.wav` (pitch preserved; [inferred] untested as a single pass; the splice alternative is allowed and reported as two passes). Ramp mode: splice per sentence, `rubberband -3 -t <factor>` on each sentence that moves (`references/ramp-mode.md`).
6. **Rests.** Neutral: per `land` gap, insert `max(0, target − measured gap)` at the silence midpoint (split-map join: the larger target, never both), filled per `room_tone_source`; with `sentence_rest_s`, every sentence-end rest is set inside its range the same way. Both modes: with `punct_pause_s`, every comma, colon and dash pause that is not a split point (Rushed delivery: fallback) is placed and sized by "Punctuation pause placement" (verified gap between the right two words, at most `target − natural gap`, run-together joins capped, skipped ones logged), not at a midpoint taken from word times (in ramp mode, inside the speech segments before the rests are set), always filled with room tone from the take's own floor, crossfaded in and out (Rules: fill rule). Ramp: rebuild the program as speech segments plus rests of the target length filled per `room_tone_source`, with the fades and tail rule above. Write `<name>_paced.wav`.
7. **Re-measure** with the same settings and hand off: the new **E** and `end_tail_s` to the closing taper (`audio-treatment` → "Sleep taper"). For an episode with picture, also hand the insert table (every pause inserted or set, in parent-take samples: `episode-conform` → data contracts → "Voice inserts"), the edit list and the new length to the voice lock (`audio-treatment` → "Voice lock"), where the timing table is measured from the locked file. Anything timed against the earlier take is now stale.

## Measure gate (the check after this step)
Run on `<name>_paced.wav` (and again on the master). A gate tool built from this table is proven first (`studio` → `references/local-jobs.md` → "Prove a check before trusting it"). **Fail** items stop the chain; **warn** items go in the report and never fail it.
| Check | Rule | Result |
|---|---|---|
| G1 transcript | no lost or doubled words vs the input transcript | fail |
| G2 rests | ramp: every rest within ±`rest_gate_pct` (15%) of its ramped or designed target; neutral: `land` rests and split joins within ±`rest_tolerance_pct`, sentence rests inside `sentence_rest_s`; both: punctuation pauses at or above their target (skipped and run-together-capped ones listed), each at a verified gap per "Punctuation pause placement" and re-checked per side on the built file; split-point marks listed as `split point`. **Replaces the old fixed-rest check.** | fail |
| G3 rest ceiling | ramp: no rest above `rest_max_s` | fail |
| G4 rate | each sentence at or under its ceiling, or listed as `capped` | warn (capped list) |
| G5 duration, E | before/after duration; new E reported | info |
| G6 loudness | whole-program `ebur128` LUFS / LRA / true peak before and after (should not move; no normalizing) | fail if moved > 0.5 LU |
| C1 per-segment loudness | per-segment LUFS spread | **warn only** |
| C2 per-segment rate | per-segment wpm spread | **warn only** |

## Output
1. Mode (pass-through / neutral / ramp), settings used ("from project" / "from skill default") and anything skipped.
2. **Edit list** (also in the `.edits.json`): Sentence (`Pn.sK`) | first words | pace | measured wpm | ceiling | stretch factor (pace, taper) | capped | boundary `rest_type` | rest target (s) | rest before -> after (s) | tail extended | flag.
3. Measure gate table with numbers; flags (capped, unmatched, long sentences, untyped split entries, designed rests cut to the ceiling).

## In Creator Studio
- **Takes:** stitched speech, directed script (`@ed`), split map, the pause notes, `project.json` `audio.pace`.
- **Makes:** `<name>_paced.wav`, `<name>.timemap` (neutral) or the splice list (ramp), `<name>_paced.edits.json`, the insert table, the report.
- **Tool:** whisper.cpp (`whisper-cli` plus a model file), ffmpeg, Rubber Band 3 or newer (`-3`). No other runtimes. Check them before this step and install what is missing (`studio` → `references/dependencies.md`); if one cannot be installed, pass through, say which tool is missing and save the install as the production's next action. Zero credits, no API calls. Run each one alone, serialized and under the watchdog (`studio` → `references/local-jobs.md`): a speech-to-text pass takes about 1.8 GB and never runs beside a render.
- **Save:** next to the input in the production folder; a `status.md` line (mode, settings, sentences stretched and capped, rests set, new E). The user's listen gate follows.
- **References:** `references/ramp-mode.md` (ramp math, split-map `rest_type`, splice commands, gate commands).
